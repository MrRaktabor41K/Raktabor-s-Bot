# 🤖 Raktabor's Bot

> Многофункциональный Discord-бот для управления сервером, общения и развлечений.

**Raktabor's Bot** — это бот, разработанный на **Node.js** с использованием библиотеки **Discord.js**.
Проект объединяет инструменты модерации, систему верификации, управление голосовыми каналами, пользовательские команды и различные вспомогательные функции.

---

## ✨ Возможности

### 🛡️ Модерация

Бот предоставляет администраторам набор инструментов для управления сервером:

* 🔨 Блокировка пользователей
* 🔇 Выдача и снятие мута
* 🧹 Очистка сообщений
* 👤 Выдача ролей
* 🚫 Снятие ролей
* 📢 Отправка сообщений от имени бота
* 🎨 Создание Embed-сообщений
* 📜 Работа с правилами сервера
* ✅ Система верификации пользователей

---

### 🎮 Пользовательские команды

Для обычных участников сервера доступны различные развлекательные и полезные команды:

* 🖼️ Просмотр аватара пользователя
* 🎱 Предсказания
* 🎲 Бросок кубика
* 🪙 Подбрасывание монетки
* 🎯 Случайный выбор
* 🔀 Генерация случайных значений
* ✏️ Управление никнеймом
* 🔊 Работа с голосовыми каналами

---

### 🔊 Голосовые каналы

Бот поддерживает систему динамических голосовых комнат.

Возможности включают:

* создание временных голосовых комнат;
* управление владельцем комнаты;
* автоматическую обработку голосовых каналов;
* проверку владельца комнаты;
* управление комнатами через отдельные функции.

## 🚀 Установка

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка конфигурации

Настройте необходимые параметры бота в конфигурации проекта.

> ⚠️ **Никогда не публикуйте токен Discord-бота и другие секретные данные в GitHub.**

### 3. Регистрация Slash-команд

```bash
node deploy-commands.js
```

### 4. Запуск

```bash
node index.js
```

После запуска бот подключится к Discord и начнёт обрабатывать команды и события.

## ⚙️ Настройка конфигурации

Перед запуском бота необходимо настроить файл config.js.

Он находится в корневой папке проекта:

Discord-Bot/
└── config.js

Откройте config.js и замените значения example на данные вашего Discord-сервера.

## 🆔 Как получить ID канала, роли или сервера

В Discord необходимо включить Режим разработчика:

Настройки → Расширенные → Режим разработчика

После этого можно нажать правой кнопкой мыши на нужный объект и выбрать:

«Копировать ID»

Например:

Сервер → Копировать ID
Канал → Копировать ID
Роль → Копировать ID

Полученный ID вставляется в config.js.

## 🎭 Настройка ролей через реакции

В REACTION_ROLES можно указать emoji и ID роли, которая будет выдаваться пользователю:

REACTION_ROLES: {
    "🎮": "123456789012345678",
    "🎨": "987654321098765432",
}

Таким образом, каждому emoji можно назначить отдельную роль.

## 📜 Настройка правил

Текст правил находится внутри rules.

Например:

rules: {
    title: "📜 Правила сервера",

    paragraphs: [
        {
            title: "1. Общение",
            text: "Уважайте других участников сервера."
        },

        {
            title: "2. Запрещённый контент",
            text: "Запрещены оскорбления, спам и публикация запрещённого контента."
        }
    ]
}

Можно добавлять любое количество разделов в массив paragraphs.

## 🔐 Важно

config.js содержит токен Discord-бота, поэтому не рекомендуется публиковать его в открытом GitHub-репозитории.

Если репозиторий публичный, добавьте config.js в .gitignore:

config.js
node_modules/
.env

После этого создайте локальный config.js на своём компьютере.
